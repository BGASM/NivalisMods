# Nivalis Borderless

Borderless windowed mode, which the game's settings don't offer: the game fills your monitor at its native resolution, and you can switch to other windows (a browser, a second screen) without the game minimising.

The game applies its own screen setting when it starts, so the mod switches to borderless a few seconds in, and again if anything switches it back.

## Settings

`BepInEx\config\bgasm.nivalis.borderless.cfg`: `Enabled = false` hands control back to the game's own screen setting (after a restart).

## Installation

Needs BepInEx 6 (IL2CPP, be.788). No other mods needed. Extract the zip into the game folder: `BepInEx\plugins\NivalisBorderless.dll`.
