# Nivalis Time Speed

Choose how fast the in-game clock runs: **0.5x** (days last twice as long), **1x** (normal) or **2x** (days pass twice as fast).

Only the clock changes: NPCs, cooking and walking run at their usual speed.

## Settings

Pause menu > **Mods** > Nivalis Time Speed > `ClockSpeed`. Applies immediately. Stored in `BepInEx\config\bgasm.nivalis.timespeed.cfg`.

## Installation

Needs BepInEx 6 (IL2CPP, be.788) and [Nivalis ModKit](https://github.com/BGASM/NivalisModKit) 0.2.0 or later. Extract the zip into the game folder: `BepInEx\plugins\NivalisTimeSpeed.dll`.

It uses the kit's shared clock, so it combines with other mods that change time instead of overriding them.
